Web game tiu xai (Vietnamese Horror Game):
- This game has a simple mechanical is the user choose "NGÚP" or "ỬA". Whatever user choose, the system random 4 choices ["NGÚP", "ỬA", "ÚP", "NGỬA"] and compares the result with user choose. If it rights, user get a special animation, if it false, users get a horror jumpscare
- UI/UX needs to be carefully polished
- Assign a lot of effects and animations to each permutation of the user's chosen result with the result. The appeal here is that the player doesn't know what animation he will encounter next, but it will slowly follow the horror scenario.
